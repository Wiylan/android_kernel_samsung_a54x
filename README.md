## 🌟 About

DΛG Kernel is a high-performance custom kernel designed specifically for Samsung Galaxy A54x devices. Built with optimization, stability, and advanced features in mind, this kernel aims to provide the ultimate Android experience.

## ⚡ Key Features

- 🎯 **Performance Optimized**
- 🤖 **Rooted variants**
- 📱 **High refresh rate**
